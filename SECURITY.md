# Security policy

## Supported versions

Only the latest `main` branch is supported. There are no release branches.

## Reporting a vulnerability

> [!IMPORTANT]
> Do not report vulnerabilities in public issues or pull requests.

Report them privately through GitHub private vulnerability reporting: open the repository's **Security** tab and select **Report a vulnerability**. Include the affected component (core library, offline tools, ROS 2 nodes, Docker image or CI), the commit you tested, and the steps to reproduce.

Vulnerabilities in GLIM, gtsam_points, glim_ros2 or other dependencies should be reported to their own projects.
